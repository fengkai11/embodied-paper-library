## 怎么开始

从[论文库](./library.md)按研究问题找一篇论文。先看“30 秒回忆”，再进入机制与证据。看完后打开[复习中心](./review.md)，先尝试自己回答，再展开参考要点。

当你想比较多个方法时，进入[技术路线](./routes.md)或[专题比较](./topics/index.md)。当你想动手验证时，进入[实验记录](./experiments/index.md)。

## 两条精读主线

**学术主线**：研究问题、方法假设、公式、训练与推理、实验、消融、局限、前后工作关系。

**工程主线**：可以复现的机制、最小实验、基线、指标、失败证据、代码和下一步行动。实验计划与已经观察到的结果分别记录。

## 如何理解内容状态

首批七篇论文是依据公开原文重新整理的**速览草稿**。它们不是历史聊天的完整导出，也不代表你已掌握或已复现。后续逐篇增加精读讨论、公式核对、图表证据与实验日志。

| 标识 | 含义 |
| --- | --- |
| 论文事实 | 能在原文或作者代码中定位的内容 |
| 作者主张 | 论文提出并试图支持的解释 |
| 研究推断 | 跨论文理解或机制解释，需要标明推理范围 |
| 待验证 | 尚需实验支持的假设 |

论文年份按第一次公开稿记录；会议发表年份另写在正文。时间线上的问题关联不表示已核实的引用关系。

## 收藏与复习记录

点击书签可收藏论文。复习卡只有在你点击“标记复习”后才生成记录，并且可以撤销。访问论文会保存最近浏览，首页据此提供返回入口。

这些个人记录保存在**当前浏览器的本地存储**，不会写入 GitHub，也不会在设备间同步。清除浏览器数据会同时清除这些记录。页面访问、收藏和复习标记都不被当作掌握程度。

## 怎样新增论文

1. 参考[精读模板](./templates/paper.md)，在仓库的 `docs/papers/` 下新增 Markdown 文件。
2. 填写文件顶部的元信息：标题、年份、分类、问题、来源、状态和关联论文。
3. 提交改动后，构建程序自动生成论文索引、搜索内容和时间线。
4. 合并到主分支且启用 GitHub Pages 后，自动更新网页。

代码与维护说明：[fengkai11/embodied-paper-library](https://github.com/fengkai11/embodied-paper-library)。
